# QL-083 Remote Operator Note

The public disabled preview now includes a second browser-local interaction: the synthetic conversation selector.

## What can be reviewed

- Brand switcher behavior for Rosie Dazzlers and Devil n Dove.
- Conversation selector behavior for hard-coded synthetic samples.
- Summary, draft-only copy, and timeline changes.
- Locked action labels and disabled controls.

## What cannot be done

The preview cannot send SMS, place calls, connect providers, register callbacks, fetch live inbox records, read or write Supabase runtime data, generate AI replies, archive transcripts, apply retention policies, or start a live pilot.

## Review target

Use this build to decide whether the selector is understandable before adding any further public preview interaction.
