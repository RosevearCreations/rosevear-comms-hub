# Telephony Boundary — QL-078 Public Disabled Preview Refinement Implementation

QL-078 implements public preview refinements only.

## Still disabled

- Provider account connection.
- Provider callbacks.
- Callback token registration.
- Live phone webhook routing.
- Live number attachment.
- SMS sending.
- Call runtime.
- Recording.
- Transcript handling.
- AI message send.
- Persistence writes.
- Live customer reads or writes.
- Archive writes.
- Retention policy writes.
- Live pilot runtime.

## Public preview allowance

The public preview may show synthetic examples, locked buttons, circled-i help markers, static status cards, and first-safe-interaction candidates.

It must not include real provider credentials, callback tokens, service-role keys, live numbers, real customer records, message bodies, transcripts, recordings, or runtime delivery paths.
