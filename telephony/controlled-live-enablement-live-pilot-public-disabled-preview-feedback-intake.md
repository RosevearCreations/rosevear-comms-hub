# QL-075 Telephony Boundary — Public Disabled Preview Feedback Intake

QL-075 is not a telephony enablement build.

The public preview may show disabled Phone/SMS controls, but it must not activate:

- Provider account connection.
- Live-number attachment.
- Callback registration.
- Phone webhook runtime.
- SMS provider delivery.
- Call runtime.
- Recording or transcription.
- AI-generated outbound sending.
- Live customer persistence.
- Archive writes.
- Retention policy writes.
- Live pilot runtime.

The only allowed outcome is static public preview feedback or deployment-gap feedback if the GitHub Pages workflow still skips.
