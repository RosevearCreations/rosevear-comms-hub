# Telephony Boundary — QL-073 GitHub Pages Disabled Preview Deployment Verification

QL-073 verifies a static preview deployment path only.

The following are not enabled:

- Provider callbacks.
- Live phone webhooks.
- SMS sending.
- Call runtime.
- Call recording.
- AI drafting for live outbound send.
- AI auto-send.
- Persistence writes.
- Live customer reads or writes.
- Archive writes.
- Retention policy writes.
- Provider account connection.
- Provider live-number attachment.
- Callback registration.
- Live pilot runtime.

The GitHub Pages preview may only expose static, browser-safe review assets.
