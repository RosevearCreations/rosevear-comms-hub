# Telephony Boundary — QL-074 Public Disabled Preview Visual Review

QL-074 does not enable telephony runtime.

## Locked paths

- Provider callbacks remain disabled.
- Live phone webhooks remain disabled.
- SMS sending remains disabled.
- Call runtime remains disabled.
- Recording and transcript paths remain disabled.
- AI sending remains disabled.
- Persistence, archive, and retention writes remain disabled.
- Live pilot runtime remains disabled.

## Public preview rule

The GitHub Pages preview may show disabled controls for review, but it must not hold secrets, live provider data, live customer data, live phone numbers, live message bodies, transcripts, recordings, or callback tokens.
