# QL-083 Telephony Boundary — Synthetic Conversation Selector Implementation

QL-083 does not enable telephony.

## Allowed

- Static public preview UI.
- Browser-local brand switching.
- Browser-local synthetic conversation selection.
- Hard-coded sample summaries, draft-only copy, and timelines.

## Blocked

- Live SMS sending.
- Phone calls.
- Call recordings.
- Provider callback registration.
- Provider account connection.
- Live number attachment.
- Phone/SMS webhook handling.
- Live customer lookup.
- Conversation persistence.
- Archive writes.
- Retention writes.
- AI reply generation or sending.
- Live pilot runtime.

The selector is a public disabled preview interaction only and must not be treated as a live communications feature.
