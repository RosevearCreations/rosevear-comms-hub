# QL-001 — Structure and Documentation Foundation

## Goal

Create the initial source-of-truth structure for Rosevear Comms Hub.

## Scope

Included:

- repository README
- docs folder
- ADRs
- brand configs
- database schema draft
- API contract draft
- telephony notes
- compliance notes
- build sequence
- placeholder folders for future code

Excluded:

- live app code
- live database deployment
- live phone provider
- SMS sending
- AI provider calls
- phone number forwarding or porting

- [ ] Brand configs exist.

- [ ] API contract draft exists.
