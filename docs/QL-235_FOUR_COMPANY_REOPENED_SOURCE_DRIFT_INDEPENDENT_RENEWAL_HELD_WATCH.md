# QL-235 — Four-Company Reopened Source Drift Aging, Independent Evidence Renewal & Conditional Release Hold Watch

- Remains a **disabled preview** for Rosie Dazzlers, Devil n Dove, iCamp and Yard Workers. All data is fictional, unsent and session-only; there are no live calls, SMS, provider activations, real approvals or external writes.
- Starts only from a currently **prepared QL-234** held-pilot source-drift packet. The model snapshots upstream source status and all twelve actual QL-181 held prerequisites with local, non-cryptographic change tokens.
- A changed or withdrawn QL-234 packet, or altered actual release-hold snapshot, freezes the downstream QL-235 scenario. An explicit case-only reset is needed, without changing other companies' ledgers.
- Each synthetic evidence gap tracks pending/matching/reopened drift renewal, an independent *unsent* referral draft, held-proof recheck status, and historical reopening/overdue counts. Reopenings are counted once per gap per simulated cycle.
- Simulated aging is measured in cycles, not calendar dates. Two cycles = due soon; three cycles = overdue. An overdue refresh must include a new independent renewal referral. Historical reopenings and late episodes continue requiring independent follow-up after a locally matching renewal.
- Open drift, pending evidence, unreviewed proof, missing independent renewal, inherited hold exceptions, overdue renewals or incomplete acknowledgements block local packet preparation. Any gap edit or new cycle clears prior check acknowledgements.
- A locally prepared packet is immutable and does not change any actual hold. Receipts contain only status enums, cycle counts, scenario/category labels and QL-181 hold states; notes, identities and source fingerprints are excluded.

## Acceptance

1. QL-235 is available as a dedicated workspace with a four-company matrix, accessible guidance, status-only receipt, links to QL-234/QL-233 and a read-only QL-181 gate register.
2. Missing/withdrawn/revised prepared QL-234 source freezes edits and packet preparation; only a confirmed case-specific reset can reopen local review.
3. Drift reopening recurrence, due-soon and overdue aging, fresh independent renewal referral, and immutable historical counters are regression tested.
4. Inherited held-proof exceptions cannot be hidden by locally matching renewal evidence; all twelve real QL-181 gates stay `HELD_UNVERIFIED`, with conditional release `BLOCKED`.
5. Only fictional complete evidence can prepare the local receipt; no real independent approval, provider dispatch or live pilot release is implemented.
