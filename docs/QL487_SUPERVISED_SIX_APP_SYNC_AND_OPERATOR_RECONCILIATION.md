# QL-487 — Supervised Six-App Source Synchronization and Operator Reconciliation

QL-487 adds a private Node-only reconciliation engine in `runtimes/master-discovery/ql487-supervised-sync.mjs` and CI tests. This is deliberately **not** a public Cloudflare endpoint or a background polling agent.

## Scope and runtime behavior
- Six canonical QL-333/485 source identifiers are isolated. A caller must explicitly select an authorized nonduplicate set and invoke `sweep({supervised:true,sourceIds:[...]})`.
- The caller is responsible for a privately configured, authenticated transport. No URL, password, client certificate, service token or source signer is fetched or generated by the library. The `fetchSource(sourceId)` dependency must be implemented on the original owner-controlled host with independent endpoint and TLS identity verification.
- Every fetched bundle must contain the exact `sourceId,noticePacket,sourceAttestationPacket,ownerPacket,reviewerPacket`. The QL-485 pinned Ed25519 source notice is verified before QL-486's independent source/owner/reviewer evidence and durable append-only receipt gates are invoked.
- A changed source Git SHA is a **source release drift** observation; it is not Comms Hub's `dev/main` Git ancestry divergence. A changed SHA, contract version, missing durable attestation, or changed event schema requires an operator HOLD/review instead of automatic approval.
- Operator reconciliation accepts an independently pinned, fresh Ed25519-signed `QL487_DECISION_SCHEMA` packet with explicit `ACKNOWLEDGE_HOLD` or `REQUEST_INDEPENDENT_REVIEW`. This is an in-memory acknowledgment only: the operator cannot edit approved pins, activate the receiver, merge branches, or promote a source.
- Read-only compatibility and explicitly supervised source evidence synchronization remain distinct from original-device certification. A transport success or signed payload cannot prove physical original runtime.
- The QL-486 journal is the only durable source evidence authority; corruption, bad signatures, failures, missing ACL prerequisites, timeout, and unsigned or stale decisions fail closed.
