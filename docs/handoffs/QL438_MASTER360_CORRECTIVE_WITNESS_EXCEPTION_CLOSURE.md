# QL-438 — Expired-Lease Corrective Action Evidence Intake, Independent Remediation Witness & Owner-Gated Incident Exception Closure Continuity

## Release boundary and source of truth

This build handles **only the OPEN expired-lease exceptions** previously preserved by QL-437. It **does not** reopen a normally closed QL-437 incident, and it **does not** enable, disable or restart a Windows receiver or claim general CONNECTED.

The successful code-level result is `DURABLE_QL438_OWNER_GATED_LEASE_EXCEPTION_CLOSURE_READBACK`: a *corrective-action exception closure receipt*, never production activation. Its outputs remain `connection=HOLD`, `activationAuthorized=false`, `slaveGate=HOLD_NEXT_MASTER_INTEGRATION_STAGE`, `runtimeUptime=UNKNOWN`. A missing or invalid fresh independent receiver OFF attestation always leaves the receiver `UNKNOWN_UNTIL_FRESH_INDEPENDENT_OFF_REVALIDATION` and retains HOLD.

This module reads from independently protected adapter interfaces but **does not install an off-host immutable store, enroll live signing keys, or create a real shutdown/remediation event**. GitHub protected CI exercises temporary Ed25519 signatures and synthetic evidence only.
