## Operational limits

This protected Node-only module is a **single isolated pilot ON evidence intake and decision boundary**, **not** a general activation command or live integration. It checks the exact terminal QL-431 reconciled incident plus QL-432, QL-433 and QL-434 private owner/readiness custody. For any success it explicitly returns **connection=HOLD**, **activationAuthorized=false**, **slaveGate=HOLD_NEXT_MASTER_INTEGRATION_STAGE**, and **manualReceiverIsolationRequired=true**. An accepted signed isolated ON observation does not prove live receiver operation until original-host and independent real signers are enrolled and observed outside GitHub CI.

The implementation **never executes receiver enable or disable commands**. A supervised host-side protection must independently enforce a hard **15-second maximum** lease and fail-closed OFF shutdown; this module validates the signed assertion that shutdown is armed. No scheduler, private signing key, independent receiver, external anchor, or real Windows runtime connection is installed by this code release.

## Negative tests and operational dependencies

Positive synthetic tests check signed OFF enrollment, independent OFF, dual-owner prepermit, durable PENDING before ON witness, independent signed ON and all three Masters, separate dual-owner post-ON recognition, one-use ACCEPTED evidence receipt and no enable call. Negative cases cover missing original-host authority, invalid prior QL-431/432/433/434 custody, overlong lease, TEMPLAR enrollment, missing fail-closed arm, bad OFF, forged or missing pre-permit, forged/ON/incorrect host evidence, missing or forged independent ON observer, duplicate/forged/incomplete Master reports, general-CONNECTED owner action, interrupted challenge with consumed PENDING, tampering and replay.

Run tests via GitHub protected evidence workflow and the normal app/Windows release gates; verify exact merge SHA post-main plus public Worker asset parity. **CI tests are simulations using temporary local Ed25519 key pairs and mock adapters; they do not establish any real original-host signer, physical ON observation, timer, key enrollment, or connected state.** In production, a real supervised host-side hard shutdown and independently verified OFF after the pilot are mandatory.
