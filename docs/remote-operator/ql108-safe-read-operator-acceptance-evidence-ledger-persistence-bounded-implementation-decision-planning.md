# Remote Operator Guide — QL-108 Bounded Implementation Decision Planning

QL-108 is a public disabled preview safe-read planning layer.

## Operator view

The safe-read panel now shows QL-108 as the active build. It summarizes the criteria that a future bounded implementation decision review must evaluate.

## What operators can verify

- QL-107 review is retained as the input.
- Implementation permission is still not granted.
- Candidate evidence fields and rejected private fields remain separated.
- Required approvals and failure dispositions are visible.
- Runtime and write paths remain blocked.

## What operators cannot do in QL-108

Operators cannot save acceptance, create evidence rows, run routes, send Phone/SMS, call providers, write archives, write audits, run retention jobs, or start a live pilot from this preview.
