# QL-118 remote operator review

Open the disabled preview, choose the Rosie Dazzlers or Devil n Dove public synthetic safe-read view, and expand Safe reads. QL-118 displays seven read-only review checks, the QL-117 owner packet agenda and questions, capture restrictions, candidate field exclusions and stop conditions. The selected brand changes only the display.

Do not enter customer/telephony data or record owner decisions. Any check in review/blocked status means the packet must be corrected before a later readiness decision. No accept/reject/defer/revise action is provided.
