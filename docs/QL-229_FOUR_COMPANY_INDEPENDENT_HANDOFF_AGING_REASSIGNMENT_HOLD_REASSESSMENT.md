# QL-229 — Four-Company Independent Handoff Exception Aging, Reassignment Outcome Reconciliation & Conditional Release Hold Reassessment

## Outcome

Add **Reassignment aging & hold reassessment** to the Quo-lite disabled-preview Operator workspace, downstream from prepared QL-228 independent handoff evidence. Four distinct organizations—Rosie Dazzlers, Devil n Dove, iCamp, Yard Workers—each retain their own session-only, synthetic case ledger. None of these outcomes represents a real owner sign-off, independent reviewer handoff or telecom pilot authorization.

## Contract

1. QL-229 begins only when QL-228 has a current prepared fictional held-continuity packet, with at least one evidence gap. The source identity includes QL-228 draft revision, outcomes, checks, cycles and synthetic note content. A missing, changed or unprepared upstream source freezes local QL-229 review. Only explicit confirmation replaces that **one case**, preserving other organizations' drafts.
2. Each gap has a fictional reassignment outcome (evidence still open, simulated match, simulated conflict), unsent reviewer follow-up action, and private in-browser rehearsal note. Each simulated conflict increments historical events at most once per gap per cycle; later invented conflicts are tracked separately.
3. Simulated reassignment follow-up is due soon after two cycles and overdue after three. An overdue entry can be updated only with a fictional independent recheck referral. A P0, repeated, disputed, previously overdue or otherwise independent-review-required gap also requires referral. Historical overdue episodes remain auditable after follow-up refresh.
4. The conditional hold reassessment packet is locally prepared only when every gap has a recorded outcome, no active overdue/referral debt remains, all three UNVERIFIED checks are acknowledged, and all twelve **actual** QL-181 release prerequisites remain HELD_UNVERIFIED.
5. Four-company overview and case panels show eligible/current/stale counts, due soon/overdue items, synthetic conflicts, referral debt and preparation state. Orphaned historical cases remain held, not silently cleared.
6. Redacted receipt exports fixed coded statuses, event counts and twelve actual hold states; it omits private notes, source fingerprints and reviewer identities.

## Safety

QL-229 is local, preview-only and read-only relative to Supabase and all providers. It makes no customer calls, SMS, database writes, independent reviewer contact or real approval. Software production GREEN is separate from real-world telecom release, which remains **BLOCKED** pending independently verified QL-181 prerequisites.
