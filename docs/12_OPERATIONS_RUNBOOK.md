# 12 — Operations Runbook

## Purpose

Simple operating procedures for future live use.

## Daily workflow draft

1. Open Communications Inbox.
2. Filter to `Needs Reply`.
3. Handle missed calls first.
4. Handle quote/custom-order requests.
5. Review AI drafts, but edit before sending.
6. Check `Needs Photos` and send reminders where appropriate.
7. Check overdue follow-up tasks.
8. Archive completed conversations.

## RosieDazzlers priority order

1. Missed calls from possible booking customers.
2. Quote requests with photos.
3. Booked customers with schedule/payment questions.
4. Weather/reschedule needs.
5. Fleet/commercial leads.
6. Low-fit or incomplete requests.

## DevilnDove priority order

1. Paid/order-in-progress customers.
2. Deadline/gift inquiries.
3. Custom order requests with reference photos and budget.
4. Product questions.
5. Maker-story follow-ups.

## Message quality checklist

Before sending a reply:

- Is the brand correct?
- Is the customer name correct?
- Are prices described as starting/range/quote as appropriate?
- Are we avoiding promises of perfect results?
- Are photo requirements clear?
- Is the next step clear?
- Are we avoiding AI hallucinated facts?

## Missed call handling

When a missed call appears:

1. Confirm brand/number.
2. Check whether contact already exists.
3. Create/follow task.
4. Send or draft callback text.
5. Link quote/custom-order form if useful.

## Incident handling

If wrong message sent:

1. Stop any automation.
2. Add internal note.
3. Notify customer if correction is needed.
4. Record incident in audit notes.
5. Fix template/rule that caused it.

If phone provider fails:

1. Check provider dashboard.
2. Switch to manual fallback.
3. Use cell phones directly if needed.
4. Log missed follow-ups after recovery.

## Manual fallback

Until phone integration is mature, the fallback is simple:

- answer calls directly
- manually create contact/conversation/task
- use templates copied from the hub
- record key promises in conversation notes
