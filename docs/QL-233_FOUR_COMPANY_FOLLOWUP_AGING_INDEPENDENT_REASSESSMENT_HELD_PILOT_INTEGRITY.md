# QL-233 — Four-Company Escalation Proof Exception Follow-Up Aging, Independent Decision Reassessment & Held-Pilot Release Integrity Audit

- Mode: **disabled-preview only**; no provider calls, SMS, persisted owner approvals, reviewer contact, Supabase writes or live gate release.
- Scope: Rosie Dazzlers, Devil n Dove, iCamp and YW. Isolated session-only ledgers, each keyed by organization and synthetic scenario.
- Input: a **current, prepared** QL-232 held-proof revalidation packet; not a new verification or authorization. A source or real QL-181 hold snapshot revision freezes downstream decisions until an explicit case-only reset.
- Follow-up aging: fictional cycle 0–12, due soon at two cycles, overdue at three. Late follow-ups require a fresh unsent independent reassessment referral. Prior overdue episodes remain visible after a fresh simulated referral.
- Independent decisions: inherited P0, prior recurrence, late disposition, newly reopened exception and proof-integrity gap all require separate reassessment or reopen drafts; none are transmitted.
- Recurrence: each gap counts at most one new simulated reopen event per cycle. Editing evidence or advancing the cycle invalidates previous local audit acknowledgements.
- Integrity: reconciling a synthetic held-pilot match never changes an actual hold. An unreviewed, locally exception-marked, inherited pending or unresolved QL-232 proof finding blocks local packet preparation; every one of the twelve actual QL-181 prerequisites stays `HELD_UNVERIFIED` and pilot release stays `BLOCKED`.
- Audit packet: three acknowledgements, current QL-232 source, zero unreviewed/overdue/missing independent reassessments or integrity exceptions and intact actual holds are required. Prepared packets are read-only.
- Export: status-only company receipt with counts, simulated cycles, enum decisions and the twelve hold states. It excludes free-text notes, raw revision tokens, contact identities and real evidence.

## Acceptance

1. The four-company operator matrix and dedicated QL-233 workspace render from the same source-linked model.
2. Missing QL-232 proof and stale/changed proof snapshots cannot produce a QL-233 packet.
3. Synthetic due/overdue transitions, referral requirements and once-per-cycle recurrence are regression-tested.
4. Changes after local check acknowledgement require those checks to be acknowledged again.
5. A held-pilot integrity exception blocks local packet preparation even with drafted independent referral.
6. All twelve actual holds remain unchanged; all external side-effect counters remain zero.
