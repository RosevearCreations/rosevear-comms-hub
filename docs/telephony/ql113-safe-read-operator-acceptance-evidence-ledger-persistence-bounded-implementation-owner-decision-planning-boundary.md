# QL-113 Telephony Boundary

QL-113 does not change telephony behavior.

## Blocked

- No Phone/SMS provider runtime.
- No outbound sends.
- No inbound SMS handlers.
- No voice callbacks.
- No DTMF handling.
- No recordings.
- No consent writes.
- No customer phone data writes.
- No live pilot runtime.

Any future telephony implementation requires a separate owner-approved implementation build and a separate implementation review build, both promoted GREEN.
