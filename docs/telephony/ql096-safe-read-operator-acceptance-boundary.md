# QL-096 Telephony and Runtime Boundary

QL-096 does not enable telephony.

Still blocked:

- inbound or outbound live calls
- SMS/MMS send or receive runtime
- DTMF processing
- provider callbacks
- recordings or transcript/archive writes
- consent, audit, admin, or retention writes
- AI generation or AI sending
- live customer/contact/provider payload reads
- live pilot runtime

QL-096 only reviews the QL-095 operator acceptance plan and keeps the public disabled preview display-only.
