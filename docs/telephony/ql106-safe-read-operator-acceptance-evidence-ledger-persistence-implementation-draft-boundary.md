# QL-106 Telephony Boundary

QL-106 does not enable telephony or messaging runtime.

Blocked in QL-106:

- Phone calls.
- SMS/MMS send or receive actions.
- DTMF, IVR, callbacks, provider webhooks, or delivery callbacks.
- Call recordings, message bodies, provider payloads, archive payloads, consent payloads, audit payloads, and retention writes.
- AI generation/send and live pilot runtime.

QL-106 only drafts future persistence requirements for review. Any telephony-adjacent evidence remains aggregate and display-only.
