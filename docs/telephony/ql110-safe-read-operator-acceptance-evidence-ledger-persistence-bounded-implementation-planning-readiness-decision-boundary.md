# Telephony Boundary — QL-110

QL-110 does not enable telephony.

The following remain blocked:

- Phone/SMS provider runtime.
- Outbound sends.
- Inbound processing.
- Provider callbacks.
- Recordings.
- DTMF.
- Consent writes.
- Live pilot runtime.

QL-110 only decides whether a later bounded implementation plan draft can be prepared. Telephony remains outside scope until separately approved, implemented, reviewed, and promoted.
