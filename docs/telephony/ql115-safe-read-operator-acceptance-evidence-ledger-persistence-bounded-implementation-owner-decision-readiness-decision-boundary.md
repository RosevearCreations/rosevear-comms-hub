# Telephony Boundary — QL-115

QL-115 does not enable telephony.

Blocked:

- Phone/SMS sends.
- Inbound handlers.
- DTMF.
- Recordings.
- Provider callbacks.
- Consent writes.
- Customer or provider contact data writes.
- Archive, audit, retention, AI, and live-pilot runtime.

QL-115 only renders display-only readiness decision evidence in the disabled preview.
