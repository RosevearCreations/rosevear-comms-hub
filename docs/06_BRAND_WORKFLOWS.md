# 06 — Brand Workflows

## Brand workspace model

Both brands use the same hub, but workflows differ.

```text
Shared system
  ├─ RosieDazzlers: detailing quotes/bookings
  └─ DevilnDove: custom/product questions
```

## RosieDazzlers workflow

### Main customer paths

- Request a detailing quote
- Ask about pricing/packages
- Book a service
- Send vehicle photos
- Ask about pet hair/odor/stains/salt
- Ask about ceramic coating or paint correction
- Ask about fleet/commercial vehicles
- Reschedule because of weather
- Follow up after quote

### RosieDazzlers intake fields

Required minimum:

- name
- phone or email
- town/service area
- vehicle type
- service requested
- preferred date/window if known
- condition notes

Recommended:

- vehicle size
- interior condition
- exterior condition
- pet hair yes/no
- odor yes/no
- stains/spills yes/no
- salt stains yes/no
- ceramic coating interest yes/no
- paint correction interest yes/no
- photos attached yes/no

### RosieDazzlers lead quality rules

Green lead:

- clear service request
- inside service area
- accepts starting-price/quote process
- sends photos when needed
- understands add-ons

Yellow lead:

- needs education
- has heavy condition issues
- wants several services but no budget clarity
- needs photos before quote

Red lead:

- wants everything for a very low price
- refuses photos for heavy-condition work
- demands guaranteed perfection
- pushes unpaid extras
- outside service area
- unsafe/biohazard/mold concerns

Internal only: never show these labels to customers.

### RosieDazzlers default follow-ups

- New quote request: follow up same day where practical.
- Needs photos: remind if no photos received after 24–48 hours.
- Quote sent: follow up after 2–3 days.
- Missed call: follow up as soon as practical.
- Weather reschedule: keep customer updated with next available option.

## DevilnDove workflow

### Main customer paths

- Ask a product question
- Request custom order
- Ask about personalization
- Ask about material/size/colour
- Ask about pickup/shipping
- Ask about deadline/gift timing
- Ask about repair/alteration possibility
- Send reference photos

### DevilnDove intake fields

Required minimum:

- name
- phone or email
- item/project type
- deadline if any
- short description

Recommended:

- budget range
- material preference
- personalization text
- colour/size preference
- reference photos
- pickup/shipping preference
- gift occasion
- safety/use concerns

### DevilnDove project categories

- jewelry
- candle
- engraving
- sublimation
- 3D print
- CNC/laser
- resin
- paracord
- repair/alteration
- general product question

### DevilnDove follow-ups

- New custom order: ask missing details before quoting.
- Needs reference photos: remind if missing.
- Quote drafted: human review before sending.
- Customer approved: move to project/work order later.
- Project complete: capture maker-story notes later.

## Shared workflow rules

- Every conversation has one brand.
- Every intake creates or links to a contact.
- Every new customer request creates a follow-up task.
- AI drafts require human approval.
- Customer promises must be stored in the conversation.
- Phone/SMS integration must preserve the same workflow.
