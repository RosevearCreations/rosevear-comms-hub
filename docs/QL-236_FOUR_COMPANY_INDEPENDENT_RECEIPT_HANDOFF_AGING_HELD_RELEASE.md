# QL-236 — Four-Company Independent Renewal Handoff Receipt Aging, Exception Recurrence & Conditional Hold Continuity

- Operating mode remains **disabled-preview** for Rosie Dazzlers, Devil n Dove, iCamp and Yard Workers. No live calls, SMS, provider activation, real independent review, owner approval, Supabase writes or automatic release.
- A case begins only from a currently prepared, fictional **QL-235 renewal-watch packet**. The upstream evidence and all twelve actual `QL-181` held-prerequisite states are snapshotted with non-cryptographic local change markers.
- A revised or withdrawn upstream packet or changed actual pilot hold freezes QL-236. The owner can explicitly reset only that fictional scenario; other companies remain isolated.
- Each fictional gap tracks an unverified independent handoff receipt, an unsent independent referral, conditional held-proof status, recurrence events and historical overdue follow-up episodes. Only one new exception counts per gap per simulated cycle.
- Two simulated cycles after a receipt is due soon; three is overdue. A new unsent independent referral is mandatory after overdue. Historical exceptions or lateness continue to require independent follow-up after a fictional matching receipt.
- Pending or exceptional receipts, inherited source hold gaps, new hold-proof exceptions, overdue cases, missing independent receipts and incomplete checks block local packet preparation. A cycle change or evidence edit invalidates previous check acknowledgements.
- A locally prepared packet is immutable and never clears real pilot holds. Privacy-minimized receipts export statuses and counts only; never notes, reviewer identity, local source tokens or real communications.

4. Prepared fictional packets require independently drafted follow-up, current held proof and three new unverified checks, without granting actual clearance.
5. All twelve real gates remain `HELD_UNVERIFIED`; live calling, SMS, providers, customer records and external writes remain disabled.
